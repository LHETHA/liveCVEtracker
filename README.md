# LiveCVETracker

## Setup Instructions

### Backend
1. `cd backend`
2. `python -m venv .venv`
3. `source .venv/bin/activate` (or `.venv\Scripts\activate` on Windows)
4. `pip install -r requirements.txt`

### Frontend
1. `cd frontend`
2. `yarn install`

## Running the Application
From the root directory:
```bash
yarn dev
